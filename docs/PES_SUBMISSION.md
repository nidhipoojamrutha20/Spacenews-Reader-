## Project description

SpaceNews Reader is an Android application built using
Kotlin and Jetpack Compose.

It retrieves spaceflight news using the Spaceflight News API,
supports article discovery and personalized interest feeds,
and stores bookmarks using Room.

The app also includes theme preferences, adjustable reading
size, and text-to-speech article summaries.
